เปียโนก้อนเมฆ

นโยบายความเป็นส่วนตัว

อัปเดต 16 ตุลาคม 2026 · ผู้พัฒนา: Peng Lin

ความช่วยเหลือและการสนับสนุนนโยบายความเป็นส่วนตัว

ขอบเขตและเวอร์ชัน

เปียโนก้อนเมฆไม่ต้องมีบัญชีหรือซื้อในแอป เพลงที่มีให้ทั้งหมด การเล่นเปียโน และการเล่นซ้ำในเครื่องใช้แบบออฟไลน์ได้ เวอร์ชัน 1.0.0 ไม่มี SDK โฆษณา ข้อกำหนดโฆษณาด้านล่างใช้ตั้งแต่ 1.1.0 เราไม่ดำเนินการเซิร์ฟเวอร์รับการเล่นเปียโนและไม่ขายข้อมูลการเล่น เวอร์ชัน 1.2.0 เพิ่มภาษาโดยไม่เปลี่ยนแนวทางข้อมูลเหล่านี้

Google AdMob และตัวเลือกความเป็นส่วนตัว

แอปใช้ Google Mobile Ads และ User Messaging Platform (UMP) แบนเนอร์อยู่ในคลังเพลงและรายการการเล่น โฆษณาเปิดแอปอาจปรากฏขณะโหลดหรือกลับหน้าหลักเมื่อเข้าเงื่อนไข โดยไม่ขัดจังหวะการเล่นหรือฟังซ้ำ หลังเล่น การดูโฆษณาแบบให้รางวัลเป็นทางเลือกและอาจรับเวลา 30 นาทีที่ไม่มีแบนเนอร์หรือโฆษณาเปิดแอป ทุกเพลงและฟังก์ชันฟังซ้ำยังใช้ได้โดยไม่ต้องดู

ข้อมูลโฆษณา

เพื่อโฆษณา วัดผล ป้องกันการฉ้อโกง และดำเนินบริการ SDK ของ Google อาจประมวลผลตำแหน่งโดยประมาณจาก IP ตัวระบุอุปกรณ์หรือแอป การแสดงและโต้ตอบโฆษณา การโต้ตอบผลิตภัณฑ์ แอปขัดข้อง ข้อมูลวินิจฉัยและประสิทธิภาพ Google และโครงสร้างพื้นฐานโฆษณาประมวลผลข้อมูลนี้ ซึ่งอาจอยู่นอกภูมิภาคของคุณ ระยะเก็บรักษาขึ้นกับนโยบาย Google และข้อกำหนดที่ใช้บังคับ ผู้พัฒนาอาจดูรายงานโฆษณาแบบรวมซึ่งไม่มีการเล่นเปียโนของคุณ

คำขอโฆษณาที่เหมาะกับวัย

คำขอโฆษณาทั้งหมดใช้การปฏิบัติสำหรับเด็ก ระดับเนื้อหาสูงสุด G และแบบไม่ปรับเปลี่ยนตามบุคคล โดยปิด ID บุคคลที่หนึ่งของผู้เผยแพร่ เราไม่ขออนุญาตติดตามของ Apple ไม่ใช้ IDFA ในเชิงรุก และไม่ผสาน Firebase Analytics การตั้งค่านี้ไม่ได้หมายความว่า SDK ไม่ประมวลผลข้อมูลทางเทคนิค คำขอโฆษณาขึ้นกับการอนุญาตของ UMP หากมีให้ใช้ ให้เปิด ผู้ปกครองและการตั้งค่า → ความเป็นส่วนตัว → ตัวเลือกความเป็นส่วนตัวของโฆษณา เพื่อเปลี่ยนตัวเลือก ผู้ปกครองติดต่อผู้พัฒนาเรื่องการประมวลผล หรือใช้ช่องทาง Google เพื่อใช้สิทธิข้อมูลที่เกี่ยวข้องได้ การเล่นและฟังซ้ำที่มีในแอปยังใช้ได้โดยไม่ต้องมีอินเทอร์เน็ต

ข้อมูลในอุปกรณ์

แอปเก็บการเล่นล่าสุด 20 ครั้ง ความคืบหน้าเพลงที่เล่นจบ ระดับเสียงเปียโน และการตั้งค่าการเคลื่อนไหวไว้ในเครื่อง การเล่นแต่ละครั้งมีชื่อเพลง เวลาบันทึก ระดับเสียงโน้ต และเวลากดกับปล่อยคีย์ การฟังซ้ำสร้างจากเหตุการณ์เหล่านี้ ไม่บันทึกเสียงรอบตัวหรือใช้ไมโครโฟน ไม่ส่งการเล่นให้ผู้พัฒนา ลบแต่ละรายการใน การเล่นของฉัน หรือล้างทั้งหมดพร้อมความคืบหน้าในการตั้งค่าผู้ปกครองได้ การถอนการติดตั้งจะลบข้อมูลในเครื่องของแอป การสำรองและกู้คืนอุปกรณ์ควบคุมด้วยการตั้งค่า Apple โปรดจัดการข้อมูลสำรองผ่านการตั้งค่า Apple

สิทธิ์และเด็ก

แอปไม่ขอสิทธิ์กล้อง ไมโครโฟน รูปภาพ ตำแหน่งที่แม่นยำ รายชื่อ หรือการติดตามโฆษณา ไม่มีแชต การโพสต์สังคมออนไลน์ หรือการอัปโหลดเนื้อหาผู้ใช้ ลิงก์ช่วยเหลือภายนอกและการล้างทุกรายการมีขั้นตอนสำหรับผู้ปกครอง เราไม่ถามชื่อ อีเมล หรือข้อมูลระบุตัวตนอื่นจากเด็ก แนวทางข้อมูลทางเทคนิคของ SDK โฆษณาภายนอกอธิบายไว้ข้างต้น

บริการ Apple

Apple จัดการดาวน์โหลด App Store การสำรองอุปกรณ์ และการวินิจฉัยระบบตามกฎของตน Apple อาจส่งข้อมูลวินิจฉัยให้ผู้พัฒนาตามการตั้งค่าแบ่งปันของระบบ SDK โฆษณาภายนอกอาจประมวลผลข้อมูลวินิจฉัยและการใช้โฆษณาตามที่อธิบายข้างต้นด้วย

อีเมลช่วยเหลือ

หากเลือกส่งอีเมล เราจะได้รับที่อยู่อีเมล ข้อความ และไฟล์แนบที่คุณส่ง ใช้เพื่อตอบ แก้ปัญหา และเก็บบันทึกช่วยเหลือที่จำเป็น โปรดหลีกเลี่ยงข้อมูลไม่จำเป็น เช่น ตัวตนเด็ก รหัสผ่าน หรือข้อมูลชำระเงิน คุณขอลบการติดต่อได้ผ่านอีเมลด้านล่าง เราจะดำเนินการกับข้อมูลที่ไม่จำเป็นต้องเก็บต่อ

เว็บไซต์นี้

GitHub Pages ให้บริการหน้าช่วยเหลือและความเป็นส่วนตัว GitHub อาจประมวลผลข้อมูลคำขอทางเทคนิค เช่น IP เพื่อให้บริการและปกป้องเว็บไซต์ เราไม่เพิ่มโฆษณา คุกกี้ หรือสคริปต์วิเคราะห์ลงในเว็บไซต์ เมื่อเปิดลิงก์ภายนอกจะใช้นโยบายความเป็นส่วนตัวของบริการนั้น
