說明與支援隱私權政策

範圍與版本

雲朵音樂屋無須帳號或 App 內購買，所有內建歌曲、彈奏與本機重播可離線使用。1.0.0 版沒有廣告 SDK，下列廣告條款自 1.1.0 版適用。我們不營運接收鋼琴演奏的伺服器，也不販售演奏資料。1.2.0 版新增在地化，不改變這些資料處理方式。

Google AdMob 與隱私權選項

App 整合 Google Mobile Ads 與 User Messaging Platform（UMP）。曲庫與演奏清單顯示橫幅；載入或符合條件的返回首頁時可能顯示應用程式開啟廣告。廣告不打斷彈奏或重播。演奏後可自願觀看獎勵廣告，獲得 30 分鐘無橫幅與應用程式開啟廣告的時間。不觀看也能使用所有歌曲與重播功能。

廣告資料

為提供廣告、衡量成效、防止詐欺及維運服務，Google SDK 可能處理由 IP 位址推估的大致位置、裝置或 App 識別碼、廣告曝光與互動、產品互動、當機、診斷與效能資料。Google 及其廣告基礎設施處理這些資料，可能在您所在地區以外處理。保留期限依 Google 政策及適用要求。開發者可能查看彙總廣告報表，其中不含您的鋼琴演奏。

適齡廣告請求

所有廣告請求採兒童導向處理、最高 G 級內容與非個人化處理，並停用發布商第一方識別碼。我們不要求 Apple 追蹤授權，不主動使用 IDFA，也未整合 Firebase Analytics。這些設定不代表 SDK 不處理技術資料。僅在 UMP 允許時請求廣告。適用時可在「家長與設定 → 隱私權 → 廣告隱私權選項」調整選擇。家長可就資料處理聯絡開發者，或透過 Google 管道行使適用的資料權利。內建彈奏與重播無網路仍可使用。

裝置上的資料

App 在本機儲存最近 20 次演奏、歌曲完成進度、鋼琴音量與動態效果偏好。演奏記錄包含曲名、儲存時間、音高與琴鍵按下及放開時間。重播依琴鍵事件產生，不錄製周遭聲音，也不使用麥克風。這些演奏不傳送給開發者。可在「我的演奏」個別刪除，或在家長設定清除全部演奏與進度。解除安裝會移除 App 本機資料。裝置備份與還原由 Apple 設定控制，請透過 Apple 設定管理備份。

權限與兒童

App 不要求相機、麥克風、照片、精確位置、聯絡人或廣告追蹤權限；沒有聊天、社群發文或使用者內容上傳功能。外部支援連結與清除全部記錄設有家長步驟。我們不向兒童索取姓名、電子郵件或其他識別資訊。第三方廣告 SDK 的技術資料處理方式如上所述。

Apple 服務

Apple 依其規則處理 App Store 下載、裝置備份與系統診斷。依您的系統分享設定，Apple 可能向開發者提供診斷資料。第三方廣告 SDK 亦可能按上述方式處理診斷與廣告使用資料。

支援電子郵件

若您選擇寄信給我們，我們會收到您提供的電子郵件地址、訊息與附件，用於回覆、排除問題及保留必要支援記錄。請避免提供兒童身分、密碼或付款資料等不必要資訊。可透過下方信箱要求刪除支援往來，我們會處理已無保留必要的資料。

本網站

GitHub Pages 託管支援及隱私權頁面。GitHub 可能處理 IP 位址等技術請求資訊，以提供及保護網站。我們未加入網站廣告、Cookie 或分析指令碼。開啟外部連結後，該服務適用其自身隱私權政策。
