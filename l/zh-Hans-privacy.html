帮助与支持隐私政策

适用范围与版本

云朵音乐屋无需账号或内购，内置歌曲、弹奏与本机回放可离线使用。1.0.0 不含广告 SDK；以下广告条款适用于1.1.0及之后的版本。我们不运营接收演奏记录的服务器，不出售演奏数据。1.2.0 新增本地化，不改变这些数据做法。

Google AdMob 与隐私选择

应用集成 Google Mobile Ads 和 User Messaging Platform（UMP）。选歌和演奏列表显示横幅；加载或返回首页的合适时机可能显示开屏广告。广告不会打断弹奏或回放。完成演奏后，可自愿看激励广告，获得30分钟无横幅和开屏广告时间。不观看也能使用所有歌曲和回放功能。

广告数据

为投放和衡量广告、防止欺诈及维护服务，Google SDK 可能处理 IP 地址推断的大致位置、设备或应用标识符、广告展示和互动、产品互动，以及崩溃、诊断和性能信息。数据由 Google 及其广告服务基础设施处理，可能在设备所在地区以外处理，保留期限依其政策和适用要求决定。开发者可查看汇总广告报告，无法通过这些报告读取演奏内容。

适龄广告请求

所有广告请求启用儿童适龄处理、最高G级广告和非个性化处理，关闭发布商第一方ID。不请求 Apple 跟踪授权，不主动使用 IDFA，不接入 Firebase Analytics。适龄处理不代表 SDK 完全不处理技术数据。广告请求以 UMP 允许状态为前提；适用时，可在「家长与设置→隐私说明→广告隐私选择」调整选择。家长可联系开发者了解数据处理，或通过 Google 提供的渠道行使适用的数据权利。断网后仍可使用内置弹奏与回放。

保存在设备上的内容

应用在本机保存最近20次演奏、歌曲完成进度、钢琴音量及动画偏好。演奏内容包括曲名、保存时间、琴键音高和按下、松开的时间。回放由琴键事件生成，不录制环境音，也不使用麦克风。这些演奏不会发送给开发者。可在「我的演奏」删除单条记录，或在家长设置中清除全部演奏与进度。卸载应用会移除本地数据；设备备份及恢复由 Apple 设置控制，应在 Apple 提供的设置中管理。

权限与儿童使用

应用不请求摄像头、麦克风、照片、精确定位、联系人或广告跟踪权限，没有聊天、社交发布或用户内容上传功能。打开外部支持页面和清除全部记录前设有家长操作步骤。不要求儿童输入姓名、邮箱或其他身份资料。第三方广告 SDK 的技术数据处理见上文。

Apple 服务

App Store 下载、设备备份和系统诊断由 Apple 按其规则处理。Apple 可能根据系统共享设置向开发者提供诊断信息。第三方广告 SDK 也可能处理上述诊断和广告使用信息。

支持邮件

主动发送支持邮件时，我们会收到你提供的邮箱、消息及附件，仅用于答复、排查问题和必要的支持记录。请勿发送儿童身份信息、密码、支付信息等不必要资料。可通过下方邮箱请求删除支持邮件，我们会处理不再需要保留的资料。

这个网站

支持与隐私页面由 GitHub Pages 托管。GitHub 可能处理 IP 地址等提供与保护网页服务所需的技术请求信息。页面未添加广告、Cookie 或访问统计脚本。打开外部链接后，相关服务适用其自己的隐私政策。
